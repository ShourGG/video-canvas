# 视频画布 · Video Canvas

在本机用一张可缩放、可连线的画布，管理 **角色与场景参考 → 分镜 → 首帧 → 视频**。

前端使用原生 HTML / JavaScript，后端使用 Python 标准库，无需 Node.js 构建步骤或数据库。通过外部 Muse 兼容图片、视频接口生成素材，项目、任务与媒体保存在本机。

## 功能

- **无限画布**：缩放、平移、拖拽排布、框选、便签、搜索定位与节点连线。
- **角色与场景**：编辑描述、生成候选图、选择固定参考图；把角色或场景连到分镜后，生成首帧时使用对应图片。
- **分镜编辑**：独立设置首帧画面、动作和机位、对白、时长、画幅及制作备注。
- **首帧与视频版本**：查看不同版本，选定首帧继续生成视频，直接播放和下载 MP4。
- **持久任务**：后台顺序处理，保存本机任务 ID 与上游任务 ID；页面刷新不影响处理，服务重启后继续查询已有任务。
- **故障续查**：查询 429、网络错误或 5xx 时退避；创建请求结果不明时标记待核对，填写原任务 ID 后续查。
- **经典视图**：保留列表式角色管理和分镜编辑页面。
- **章节导出**：可按画布选定的视频版本拼接，保留音频并生成 SRT 与烧录字幕成片。

## 快速开始

需要 Python **3.10 或以上**。仅运行画布无需安装第三方 Python 包。

```bash
git clone https://github.com/ShourGG/video-canvas.git
cd video-canvas
python setup_demo.py
python server.py
```

浏览器打开 **<http://127.0.0.1:7790/canvas>**。服务默认仅监听 `127.0.0.1`。

`setup_demo.py` 创建“山间驿站”示例：两个人物、一个场景、两个分镜和一张便签。初始化不会覆盖已有同名文件；不需要示例时使用：

```bash
python setup_demo.py --empty
```

Windows 用户也可以在初始化后双击 `启动视频工作台.bat`。该脚本会启动本机服务，或打开已在 7790 运行的工作台。

不希望自动打开浏览器时：

```bash
python server.py --no-browser
```

自定义端口（手动启动）示例：

```powershell
$env:STUDIO_PORT = '7800'
python server.py
```

```bash
STUDIO_PORT=7800 python server.py
```

### 配置接口

从画布工具栏进入“经典视图”，点击“设置”，填写：

| 配置项 | 示例或说明 |
|---|---|
| 接口地址 | `https://api.example.com/v1`，包含 `/v1` |
| API Key | 使用自己的接口凭据 |
| 图片模型 | 默认 `muse-image` |
| 视频模型 | 默认 `muse-video` |
| 角色画幅 | 默认 `3:4`，分镜可单独指定 `16:9` 等比例 |
| 统一风格 | 角色定妆与分镜视频分别设置 |

示例配置的地址和 Key 均为空，初始化和浏览画布不会自动发出生成请求。实际生成需要可用的外部接口与额度。

**接口需要实现本项目使用的异步任务协议**；仅支持 `/chat/completions` 的通用 OpenAI 兼容服务不能直接替代。字段示例见 [接口说明](docs/API.md)。

### 一次制作流程

1. 编辑角色或场景，生成候选图，并选定参考图。
2. 双击分镜卡片编辑；从角色或场景节点右侧端口拖线到分镜，建立参考关联。
3. 生成首帧，检查构图和人物；有多个版本时切换到满意的一张。
4. 使用选定首帧生成视频；也可选“首帧 → 视频”连续处理。
5. 播放视频、检查对白与动作，选定版本后下载或导出章节。

视频是否包含可用人声、准确台词或同步口型，取决于上游模型的实际结果，需要试听确认。

## 操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 以光标为中心缩放 |
| 拖动空白处 | 平移画布 |
| 拖动节点 | 调整位置 |
| Shift + 拖动空白处 | 框选节点 |
| 双击卡片 | 打开编辑栏 |
| 双击空白处 | 新建便签 |
| 从右侧圆点拖线 | 连接节点；角色、场景到分镜的连接参与参考图生成 |
| Delete / Backspace | 删除选中便签、连线或移除画布中的关联 |
| Escape | 清除选择、关闭编辑栏 |

位置、便签、连线和首帧 / 视频选择保存到 `canvas.json`；画布视角保存在浏览器本地存储。

## 数据与任务恢复

| 本机文件 / 目录 | 用途 |
|---|---|
| `config.json` | 接口地址、Key 与模型配置 |
| `characters.json` | 角色、场景描述与选定参考图 |
| `shots.json` | 分镜、对白及参考关联 |
| `canvas.json` | 画布布局、连线、便签、选定版本 |
| `角色图/` | 角色和场景图片与生成元数据 |
| `视频任务/<id>/` | 持久任务记录、首帧、MP4 |

这些本机运行数据均由 `.gitignore` 排除。仓库仅提供空凭据配置模板与通用示例，不附带实际制作项目或生成素材。

已有任务的上游 ID 会持续保留。创建请求超时且没有取得 ID 时，先在原接口工作台核对，找到原 ID 后续查；不要直接重复创建。“暂停本机查询”不会取消上游生成。生成期间修改节点地址会暂停旧节点任务，恢复原地址后可以续查。

这是单机工具，不提供多用户登录或跨机器并发编辑。Key 以明文保存在本机 `config.json`，状态接口只返回是否已配置；请将项目数据目录保存在自己的电脑上。

## 导出章节视频（可选）

安装导出依赖：

```bash
python -m pip install -r requirements.txt
python 导出整章.py
```

也可以传入章节名片段筛选：

```bash
python 导出整章.py 山间驿站
```

导出使用 `canvas.json` 中选定的视频版本，否则选最近完成版本。按分镜顺序统一为 1280×720 / 25 fps，保留音轨，对没有音轨的片段补静音，生成 MP4 和 SRT，写入项目上一级的 `成片/` 目录。未完成的镜头会跳过并在终端列出。

FFmpeg 由 `imageio-ffmpeg` 提供。烧录字幕使用系统字体，默认 `Microsoft YaHei`；Linux 或 macOS 可以在 `导出整章.py` 的 `SUB_STYLE` 中换为已安装的中文字体。字幕时间按文本长度分配，需要精细同步时再调整 SRT。

## 开发与验证

```bash
python -m unittest discover -v
node --check canvas.js
node --check studio.js
```

测试使用本机模拟接口，验证新项目初始化、画布保存、状态脱敏、任务去重、提交结果不明、429 退避、重启续查、原结果重新下载、首帧复用等行为，不消耗生成额度。GitHub Actions 在 Windows 与 Linux 上运行相同检查。

```text
server.py                 本机 HTTP 服务、配置和图片生成接口
video_jobs.py             首帧与视频任务、持久化、恢复
canvas.html / canvas.js   节点画布与编辑栏
index.html / studio.js    经典角色与分镜视图
setup_demo.py             无覆盖初始化
examples/                 空凭据配置与通用故事示例
导出整章.py               章节拼接、音轨和字幕导出
docs/API.md               本机接口与上游协议说明
test_*.py                 不调用真实上游的测试
```

画布需要 Python 后端处理保存和生成，不能仅用 GitHub Pages 静态托管运行完整功能。
